# LUXE — Fashion & Clothing Website

LUXE is a modern, responsive fashion and clothing website developed using HTML, CSS, and basic JavaScript. The website showcases clothing collections, product categories, seasonal trends, and an interactive shopping interface.

## ✨ Features

- **Responsive Design:** Works on desktops, tablets, and mobile devices.
- **Modern Homepage:** Stylish hero section featuring the latest seasonal collection.
- **Product Categories:** Browse Women, Men, and Accessories.
- **Trending Products:** Display of eight sample fashion products.
- **Category Filtering:** Filter products by category.
- **Product Search:** Search products by name or category.
- **Shopping Cart:** Add and remove products from the shopping bag.
- **Dynamic Pricing:** Automatically calculate cart subtotal and item count.
- **Local Storage:** Preserve cart items using browser `localStorage`.
- **Mobile Navigation:** Responsive navigation menu for smaller screens.
- **Newsletter Subscription:** Interactive email subscription form.
- **Seasonal Trends:** Dedicated section showcasing fashion trends.
- **Demo Checkout:** Basic checkout interaction for demonstration purposes.

## 🛠️ Technologies Used

- **HTML5** — Website structure and content.
- **CSS3** — Styling, layouts, animations, and responsive design.
- **JavaScript** — Product filtering, search, cart functionality, and form interactions.

## 🚀 How to Run the Project

1. Download or clone the project repository.
2. Extract the project files if downloaded as a ZIP.
3. Ensure that `index.html`, `style.css`, and `script.js` are in the same folder.
4. Open `index.html` in any modern web browser.
5. Explore the product categories, search for products, and test the shopping cart.

**No additional software, frameworks, or package installations are required.**

## 🛍️ How to Use

1. Browse the homepage and seasonal collection.
2. Navigate to the Shop section.
3. Select a category to filter the products.
4. Use the search icon to find a product.
5. Click **ADD TO BAG** to add a product to the cart.
6. Open the shopping bag to view items and the subtotal.
7. Remove products when required.
8. Try the newsletter form to see the confirmation message.

## ⚠️ Limitations

- Product images and Google Fonts require an internet connection.
- The checkout feature is for demonstration only and does not process real payments.
- Newsletter submissions display a local confirmation message and are not sent to a server.
- Product information is sample data maintained in JavaScript.
- Cart information is saved in the browser using `localStorage`.
